Disclosure

    
Synthetic demo. BBS SG Bank is fictional; all accounts, balances and operations are generated locally. No real customers, credentials or banking systems are involved.

    
The nightly batch is a real local COBOL job when the helper server is running; simulated screens are labelled SIMULATED on the terminal itself.

  


  

    
Start the terminal

    
From the repository root:

    
legacy-ui/run.sh

    
then open http://127.0.0.1:8792/. Opened as a plain file, the terminal runs in labelled SIMULATED mode with embedded data.
